THE STORY BEHIND THE PROJECT

Built from curiosity.
Made for PC builders.

AUAU Builder PC Local started with my interest in computers, PC hardware and custom computer building. I wanted to create a practical tool that helps people organize their components, save configurations and compare different builds.

I was also curious about artificial intelligence and wanted to explore how an AI model could work directly on a personal computer. This inspired me to integrate a local Qwen3 model into the application.

Developed as an individual Portfolio Project at Holberton School, this project brought together frontend development, backend programming, databases and local AI.

YOUR COMPUTER. YOUR ENVIRONMENT.

Run AUAU Builder locally.

Download the source code, install the dependencies and prepare the SQLite database and the Qwen3 GGUF model before launching the application on your computer.

1. Download the source code

Download the project ZIP ↗

2. Install dependencies

npm install

3. Prepare the environment

Configure your SESSION_SECRET, prepare a compatible SQLite database, and place the Qwen3 model at models/qwen3-4b-q4_k_m.gguf. See the README for database setup details and GPU requirements.

4. Start the server

npm start

5. Open the application

Open local application ↗

The link works after the server has been started on your own computer.
